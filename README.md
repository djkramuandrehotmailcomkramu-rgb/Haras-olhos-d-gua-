# Haras-olhos-d-gua-

## Pluviômetro (PWA)

App de coleta de chuva por talhão (`index.html`): painel, lançamento em teclado numérico, mapa, histórico, relatório (WhatsApp, PDF, CSV) e backup. Abra o site publicado no celular e use "Adicionar à Tela de Início". Funciona offline; os dados ficam no aparelho e são trocados entre aparelhos por backup.

## Controle de Safra (`controle-safra/`)

PWA de controle da colheita de soja da Fazenda Lagoa Formosa (pesagem, talhões e dashboard). Dados no Supabase (tabelas `cs_*`, RLS por perfil), com fila offline no aparelho. Abra `controle-safra/` publicado e use "Instalar aplicativo".
