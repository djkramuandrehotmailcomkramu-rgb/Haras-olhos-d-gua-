# Haras-olhos-d-gua-

## Pluviômetro (PWA)

App de coleta de chuva por talhão, na pasta [`pluviometro/`](pluviometro/). Abra `pluviometro/index.html` pelo site publicado e use "Adicionar à Tela de Início" para instalar. Funciona offline; os dados ficam no aparelho e são trocados entre aparelhos por backup.
